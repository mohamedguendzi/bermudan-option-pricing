# Bermudan Option Pricing: Polynomial and Neural Network Regression

Longstaff–Schwartz algorithm with two interchangeable estimators of the continuation value:
least-squares regression on total-degree polynomials, and a one-hidden-layer neural network.
Puts, geometric baskets and max-calls, up to 50 underlying assets.

- Report: [`report/report.pdf`](report/report.pdf)
- Code: [`PricerBermudan.ipynb`](PricerBermudan.ipynb)

Following B. Lapeyre and J. Lelong, *Neural network regression for Bermudan option pricing*,
Monte Carlo Methods and Applications, 2021.
